# Portrait Production Quality Rules

**Status:** approved for Phase 12+

## Reject / mark `needs-regeneration` if any apply

- Incorrect species anatomy or wrong animal
- Extra limbs, eyes, ears, horns, wings (unless species/card requires)
- Malformed teeth, beak, jaws, tusks
- Broken or melted facial structure
- Unreadable silhouette at thumbnail size
- Style drift (looks like another game / photo / chibi)
- Background too busy / full landscape competing with subject
- Bad crop (cut off critical features accidentally; or Moses III showing full head)
- Excessive glow, neon outlines, VFX spam
- Childish / cute-mascot appearance
- Any unintended text, numbers, letters, watermarks, UI, frames, power bars
- Horror/gore (blood, open wounds)

## Dragon of Moses III specific reject rules

- Full head visible
- Looks like a random zoom of a normal dragon portrait
- Scale does not feel intentional / extreme

## Pass criteria

- Matches `docs/card-art-direction.md`
- Matches card-specific prompt + manifest pose/camera
- Portrait-only (no baked card chrome)
- Consistent with suit atmospheric family
